# VKR SCADA System

Распределенная SCADA-система, организованная по принципу монорепозитория. Включает в себя веб-конструктор мнемосхем, панель мониторинга и серверную часть.

## Структура проекта

### Клиентские модули (Client Modules)

* `/client/` — React SPA shell. Единая точка входа, предоставляющая публичную зону, панель администратора (Admin Hub) и панель пользователя (User Hub). Встраивает `/constructor` и `/dashboard` через компоненты-обертки.
* `/constructor/` — Клиентский модуль визуального реактора (холста) для проектирования дашбордов, размещения виджетов и настройки привязки.
* `/dashboard/` — Клиентский модуль операторского интерфейса для рендеринга готовых мнемосхем и оперативных данных в реальном времени.

### Серверные модули (Server Modules)

* `/cloud_server/` — Облачный бэкенд для агрегации данных, глобальной синхронизации состояния и хранения конфигураций мнемосхем.
* `/edge_server/` — Пограничный контроллер (локальный сервер) для управления и общения с реальным (физическим) оборудованием по промышленным протоколам.

## Особенности разработки (Spec-Driven Development)
Этот проект был создан с применением ИИ-агентов. В папке /specs находятся файлы документации, сгенерированные нейросетью для удержания контекста при разработке.
Файлы спецификаций и задач по модулям использовались для передачи точного контекста агентам.
Файлы agents.md содержат описание ролей и системных промптов, которые я настраивал для управления процессом генерации кода, для каждого модуля файл свой и находится в папке модуля.
Я выступал в роли архитектора и ревьюера: проектировал структуру, настраивал агентов, ставил задачи и проводил отладку сгенерированного кода.
Скиллы и воркфлоу находятся в папке /agent. В основном там готовые скиллы от github spec kit, я под проект писал еще 2 вариации implement скиллов.
В папке /slices доки с пайплайном планирования разработки вертикальных срезов, применялись на поздних этапах разработки, когда внедрение функционала требовало изменений в нескольких модулях, а основной пайплайн стал избыточным.
